MOMOYO PANCING WEBSITE
======================

File:
- index.html : struktur halaman website
- style.css  : tampilan, warna, responsif, dan animasi
- script.js  : animasi intro, filter menu, galeri, navigasi, tombol order
- assets/    : gambar-gambar yang dikirim, sudah dipasang di website

CARA MENJALANKAN
1. Ekstrak ZIP ini.
2. Jangan pisahkan folder assets dari index.html, style.css, dan script.js.
3. Klik dua kali index.html untuk membuka website di browser.
4. Internet diperlukan untuk font Google; website tetap bisa tampil tanpa font tersebut.

BAGIAN YANG PERLU DIEDIT
- Harga dan nama menu: cari nama menu/harga di index.html.
- Link voucher/order: cari `voucherURL` di script.js dan link `vt.tiktok.com` di index.html.
- Alamat, Instagram, TikTok, dan Google Maps: cari bagian `visit` dan `footer` di index.html.
- Gambar: ganti file di folder assets dengan nama file yang sama, atau ubah path src di index.html.

Catatan: nama menu dan harga saat ini adalah contoh sementara karena daftar harga resmi belum diberikan.
